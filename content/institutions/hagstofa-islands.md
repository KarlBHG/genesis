# Hagstofa Íslands

## Summary
Stjórnarráðið's institutions list places Hagstofa Íslands under Forsætisráðuneytið. This record stores that published oversight line as a typed authority edge from [[prime-ministers-office]].

The trade-flow records in this map, including [[goods-imports-2024]] and [[goods-exports-2024]], already cite Statistics Iceland publications as their source pages. This page adds the institution itself so those flows can be read as outputs from a named public body, not an anonymous data feed.

The pages opened for this pass print no single founding date and no standalone line-item amount for Hagstofa that can be stored as a source-bound `funds` amount.
